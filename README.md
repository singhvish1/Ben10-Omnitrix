# Omnitrix for Apple Watch

A SwiftUI watchOS app inspired by the Ben 10 Omnitrix.

## Features

- Swipe left or right on the dial to select an alien.
- Tap **ACTIVATE** for a transformation state and haptic feedback.
- Alien-specific colors, symbols, species, and powers.
- Dark, high-contrast watch-sized interface.

## Run

Open [`Ben10Omnitrix.xcodeproj`](./Ben10Omnitrix.xcodeproj) in Xcode and choose an Apple Watch simulator or paired Apple Watch as the run destination. The project targets watchOS 10 or newer.
